## 2. 当前版本包含

- Vue 3 前端和 Spring Boot Java 后端。
- CCE 前后端分离部署。
- CCE 内网 Ingress 和 ClusterIP Service。
- 外部 TDSQL/MySQL 兼容数据库。
- HttpOnly Cookie 登录。
- 管理员和普通成员角色。
- 管理员创建、停用、启用和重置用户。
- 管理员管理任务分类及颜色。
- 任务标题、日期、截止日期、分类、跟进人、状态和进度。
- 普通成员只能新增和编辑自己负责的任务。
- 任务乐观锁和 409 冲突提示。
- 甘特图、日期横向滚动和筛选。
- Flyway 数据库迁移。
- 修改密码和旧会话失效。

## 3. 明确不包含

当前版本不包含：

- WebSocket 实时同步。
- 自动轮询刷新。
- 离线编辑。
- CRDT 冲突合并。
- 甘特图拖动改期。
- 评论、通知、附件和操作历史。
- 多项目层级。
- 子任务和任务依赖。
- 一个任务多个跟进人。
- 内置短信、邮件或企业微信通知。
- 自动化 CI/CD 流水线。
- 自动备份和自动灾备切换。

## 4. 已知限制

### 任务数量

甘特图采用浏览器端绘制，当前设计目标是不超过 500 条任务。任务量明显增加时，应评估分页、虚拟滚动或专业甘特图库。

### 数据库连接

后端每个副本默认最多 10 个数据库连接。扩容后端副本前，必须确认 TDSQL 最大连接数和账号配额：

~~~text
最大连接数约等于后端副本数 × DB_POOL_MAX_SIZE
~~~

### 日期和时区

任务日期使用 DATE，不保存时分秒。截止日期包含当天。后端数据库时区配置为 UTC，跨时区使用时应保持日期口径一致。

### 用户和权限

- 普通成员可以查看全部任务，但不能编辑他人任务。
- 一个任务只有一个跟进人。
- 停用用户的历史任务不会自动转移。
- 未匹配的旧负责人需要管理员手动处理。

### 访问范围

应用设计为企业内网使用。若要开放公网访问，必须重新评估认证、WAF、限流、审计、密码策略和数据安全，不能直接修改 Ingress 为公网入口。

## 5. 迭代规则

### 不涉及数据库的前端或后端发布

1. 修改代码和测试。
2. 通过 lint、单元测试和生产构建。
3. 生成新的 Git commit 和镜像标签。
4. 推送前后端镜像。
5. 修改 backend.yaml、frontend.yaml 的镜像标签。
6. 执行滚动发布和功能验收。

### 涉及数据库的发布

1. 先编写新的 Flyway migration。
2. 在测试数据库执行并验证。
3. 备份生产 TDSQL。
4. 使用对应版本后端镜像执行 migration Job。
5. 确认 Job 成功后发布应用。
6. 不删除或修改已经执行成功的 Flyway 版本。

### 回滚规则

应用镜像可以回滚，但数据库迁移默认不可自动回滚。数据库变更必须考虑向前兼容、备份恢复和人工回退方案。

## 6. 后续建议

优先级建议：

1. 增加正式的数据库自动备份和恢复演练。
2. 增加 CCE 监控、告警和日志留存。
3. 增加操作审计和任务变更历史。
4. 增加并发和容量压测。
5. 任务量超过 500 条后优化甘特图渲染。
6. 根据业务需要增加通知、评论和附件。
