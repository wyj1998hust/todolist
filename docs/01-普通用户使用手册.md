# TodoList 普通用户使用手册

## 1. 登录系统

1. 在企业内网打开项目地址，例如：

   ~~~text
   http(s)://todo.intra.example.com/
   ~~~

2. 输入管理员或普通成员分配的用户名和密码。
3. 登录成功后进入甘特图首页。
4. 首次登录后建议立即修改密码。

密码只用于登录，不会保存在浏览器中。浏览器可能记住上一次成功登录的用户名，但不会保存密码。

## 2. 甘特图首页

登录后默认显示所有任务的甘特图：

- 左侧显示任务名称、分类、跟进人、状态和进度。
- 右侧按日期显示任务时间条。
- 时间条长度由开始日期和截止日期决定，截止日期包含当天。
- 时间条颜色使用任务分类颜色。
- 进度覆盖层表示已完成比例。
- 可以横向滚动查看较远日期。

系统默认只显示任务，不自动实时刷新。需要查看其他用户刚刚提交的内容时，点击页面上的“刷新”按钮。

## 3. 查询和筛选任务

可以按照以下条件筛选：

- 任务分类。
- 跟进人。
- 任务状态。

清空筛选条件后可以恢复查看全部任务。普通成员可以查看全部任务，但查看权限不代表可以编辑全部任务。

## 4. 新增任务

点击“新增任务”，填写：

- 任务标题。
- 开始日期。
- 截止日期。
- 任务分类。
- 任务状态。
- 任务进度。

普通成员新增任务时，跟进人会自动设置为当前用户，负责人选择器不可修改。后端也会再次校验这一规则。

填写规则：

- 标题不能为空。
- 开始日期不能晚于截止日期。
- 分类必须是启用状态。
- 进度必须为 0 到 100。
- 进度为 100 时，任务会自动变为“已完成”。

## 5. 编辑任务

点击自己负责的任务条或任务编辑按钮，可以修改：

- 标题。
- 开始日期和截止日期。
- 分类。
- 状态。
- 进度。

普通成员不能：

- 编辑其他成员负责的任务。
- 编辑未分配任务。
- 修改任务负责人。
- 删除任务。

如果任务已被其他人修改，系统会提示任务版本冲突。此时先刷新页面，确认最新内容后再重新编辑。

## 6. 修改密码

1. 打开右上角用户菜单。
2. 选择“修改密码”。
3. 输入当前密码。
4. 输入 8 到 100 个字符的新密码。
5. 确认提交并重新登录。

修改密码后，其他设备上的旧登录会话会失效。

## 7. 任务状态说明

| 状态 | 含义 |
|---|---|
| 未开始 | 进度为 0，任务尚未执行 |
| 进行中 | 已开始执行但进度未达到 100 |
| 已完成 | 进度为 100，或手动选择完成状态 |

## 8. 常见问题

| 问题 | 处理方式 |
|---|---|
| 登录失败 | 确认用户名、密码和账号是否被管理员停用 |
| 看不到新任务 | 点击刷新，确认筛选条件已清除 |
| 无法编辑任务 | 只有任务跟进人或管理员可以编辑 |
| 无法选择某个分类 | 分类可能已被管理员停用 |
| 提示版本冲突 | 刷新页面后重新打开任务并编辑 |
| 修改密码后无法继续操作 | 使用新密码重新登录 |

问题反馈时，请提供操作时间、页面提示和任务名称，不要在聊天或工单中发送密码。
