# TodoList 项目交付总览

## 1. 项目基本信息

| 项目 | 内容 |
|---|---|
| 项目名称 | TodoList 团队任务协作系统 |
| 当前技术栈 | Vue 3、Vite、Pinia、Element Plus、Java 17、Spring Boot、MySQL/TDSQL |

| 当前前端版本 | frontend/package.json 中的 1.0.0 |

## 3. 交付前必须填写的实际信息

以下信息不能继续使用示例值，应由项目实施人员填写在企业内部交付记录中：

- Git commit 或 Release Tag。
- 前端镜像完整地址和标签。
- 后端镜像完整地址和标签。
- CCE 集群名称和命名空间。
- 内网域名、Ingress Class 和内网 ELB 地址。
- TDSQL 地址、端口、数据库名和数据库账号。
- TDSQL 白名单、安全组和网络责任人。
- CCE、SWR、TDSQL、DNS 的运维责任人。
- 初始密码交接方式和密码保管人。

生产密码、JWT Secret、TDSQL 密码和 TLS 私钥不应写入 Git 或普通交付文档，应通过企业密钥管理系统或安全渠道交接。

## 4. 当前交付基线

交付前执行：

~~~powershell
git status --short
git log -1 --oneline
git tag --list
~~~

交付包应固定到一个干净的 Git commit。前端和后端镜像必须使用不可变标签，例如 20260801-001，不建议生产使用 latest。
