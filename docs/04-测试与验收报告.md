## 4. 可重复执行的自动化命令

### 前端

~~~powershell
cd F:\myProject\todolist\frontend
npm ci
npm run lint
npm run test
npm run build
~~~

### 后端

~~~powershell
cd F:\myProject\todolist\backend
mvn -B test
~~~

如果本机未将 Maven 加入 PATH，可使用已安装目录中的 Maven：

~~~powershell
F:\apache-maven-3.9.16\bin\mvn.cmd -B test
~~~

### 本地容器

~~~powershell
cd F:\myProject\todolist
docker compose up --build -d
docker compose ps
curl.exe -i http://localhost:8081/health
curl.exe -i http://localhost:8081/api/health
~~~

## 7. 并发和乐观锁验收

使用两个浏览器或两个隐身窗口：

1. 用户 A 和用户 B 同时打开同一任务。
2. 用户 A 先保存，任务版本号增加。
3. 用户 B 使用旧版本保存。
4. 用户 B 应收到 HTTP 409 Conflict。
5. 用户 B 刷新后重新编辑，保存成功。

5 人并发验收至少安排：

- 5 个账号同时登录。
- 5 个账号同时查询和刷新甘特图。
- 同时新增至少 5 个任务。
- 同时编辑不同任务。
- 任选两个账号编辑同一任务，确认冲突提示。
